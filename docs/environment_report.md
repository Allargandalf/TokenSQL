## 对开发有用的结论

- 项目运行于远端 Linux，使用独立 Python 环境和 uv，不修改共享依赖或其他用户服务。
- 数据层以 SQLAlchemy/Alembic 为基础；SQLite 支持当前 MVP/测试，PostgreSQL 的真实部署需单独验收。
- Excel 样表存在多 Sheet、合并单元格、公式缓存、混合计费单位及缺失业务上下文；原件不公开，留在远端。
- 旧 Qwen2.5 服务调查属于历史背景；新版优先复用已暴露的 Strata 标准接口，不启用旧32B。
- 语义抽取、JSON 输出、工具调用和 coding/报价并发仍须按新版计划真实测试；服务可用不等于这些业务能力已验收。
- 外网与官方页面可能存在地区限制或动态内容；采集失败不得伪造成功，应留下异常/来源记录。
