# 模型比价与供应商报价更新

更新：2026-10-29。适用 v2.4「按供应商路由」。供应商档案、专属对话和新旧表格读取见[供应商路由说明](supplier_routing.md)。

## 日常比价

1. 在模型概览搜索 model_id，分别看输入和输出的最低可比价及供应商。
2. 进入模型排行，选择计费场景。忙闲、市场、平台、上下文、缓存TTL、模态、会员及含税条件不同的报价分开比较，不混成一个最低价。
3. 默认按供应商价升序，可切换降序、折扣或日期；先取齐筛选结果再排序分页，并列最低均标记。
4. 官网参考价在顶部，完整细则在详情；主表只出现供应商价与折扣。整模折扣只读展开，指定项例外优先，不增加数据库记录。
5. 统一币种/单位仍是显示计算；导出使用相同筛选、排序和计算依据。跨量纲估算单独标明，不宣称严格最低价。缺官网但已明确的供应商金额仍可比较，纯折扣缺官网时金额显示未知。
6. 编辑、删除、批量删除仍操作原报价；详情中的派生价不会反填原值。新报价批准时自动创建缺失模型。

供应商报价必须填写供应商。一个批次可以先选现有供应商或明确新建；缺供应商会等待补充，不会默填“未知”。官网价格和模型实体维护不要求供应商。

## 新版报价单覆盖旧报价

使用“更新供应商报价”入口，选择供应商及稳定的来源范围，例如“主流API周报价”。来源范围是报价单系列/业务范围，不是每次变化的文件名。

- 增量更新是默认模式：新增或修改文件中明确列出的条目；未出现的旧报价不动。删除必须明确指出。
- 完整替换：仅在明确确认本文件完整覆盖所选来源、工作表、模型和渠道范围时，才把范围内缺失的旧条目列为删除。
- 多sheet必须核对读取覆盖；部分解析、有待补充或漏sheet不得用缺行触发删除。
- 首次确认范围后可以沿用同一范围；范围扩大或切换完整替换必须重新确认。

上传文件并填写Prompt后，审核按“新增、修改、删除、不变、待确认”分组。修改显示前后值，删除显示原因。遇到多个旧候选可选择覆盖某条、新增或忽略；金额、折扣、行号及文件名不是报价身份。无歧义时整批一次确认。

系统原位修改旧行并保留quote_id，新增缺失行，删除确认行；其他供应商、其他来源、手工报价和官网目录不属于该文件的缺失删除范围。普通报价更新不建立每期数据库或Excel备份，保留既有审计与轻量回执。

## 重传、旧文件与并发

- 相同内容换文件名重传不会重复新增；调行序也不改变稳定身份。
- 文件有版次或生效日期时用于新旧识别；已知旧版或同版变内容需要额外确认。
- 无法确定文件新旧时，需要用户确认当前最新；上传时间不当作报价生效日期。
- 同文件修正Prompt、映射或解析后可重新预审，不以文件SHA阻止真实纠错。
- 审核期间数据库变化会拒绝旧提交，按最新目录重新对账并要求再确认；不是简单刷新revision强行覆盖。
- 取消或校验失败不产生部分业务写入；取消后原件回input。

## 等待补充和布局

等待问题放在聊天滚动区的一张卡片中，顶部只保留紧凑状态，输入框保持可见；证据和长解释按需展开。可以拖动左右分隔条调整报价/聊天宽度，以及聊天/输入区高度，也支持键盘和恢复默认。窄屏在报价与聊天之间切换。

补答继续使用原job、会话和文件。仅缺供应商时选择并确认整批供应商可直接重新预审，不必重新上传、重新调用模型。

## 接口简要

- GET/POST /api/workspace/suppliers：读取或确认供应商；已有供应商按稳定ID关联，别名只接受人工确认，不模糊合并。
- POST /api/workspace/supplier-updates/preview：SupplierReconciliationRequest → bundle、groups、ready、base_catalog_token、review_digest。纯预览不写业务库。
- POST /api/workspace/supplier-updates/apply：request + expected_catalog_token + expected_review_digest + import_id → 同事务应用及回执。
- /imports/start 与 /agent/messages 可携带 supplier_id、update_request；导入文件指纹由宿主计算，模型不能改写人的确认权限。
- 更新审核沿用 /imports/{id}/proposal 修订及 /confirm、/cancel；过期时重新预览再确认。

request中的mode为incremental/full；source_scope与supplier_id为范围，expected_sheets/covered_sheets/complete_read为完整性证据，source_version/source_effective_date为来源时间信息，scope_confirmed/latest_confirmed/allow_rollback为人工授权。模型只提出条目和证据，不自行授予删除范围或回滚权限。
